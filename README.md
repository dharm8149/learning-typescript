# Learning TypeScript — Interactive Educational Web Platform

An interactive full-stack web application designed to master TypeScript through:
- 📖 **In-Depth Conceptual Explanations** (MDX guides with live playgrounds)
- 🎬 **Animated Explainer Videos** (Powered by [Remotion](https://www.remotion.dev/))
- 🎮 **Interactive JS/TS Mini-Games** (Multiple game modes, level progression, and boss battles)
- ⚡ **Vite + Express Monorepo** (Fast frontend, resilient backend with TypeScript Compiler API sandbox)

---

## 📚 Project Documentation

- **[Detailed File Structure & Architecture Guide](PROJECT_STRUCTURE.md)**: Full monorepo directory layout, subsystem breakdowns, game modes, and Remotion integration specs.
- **⚡ Zero-Restart Auto-Discovery**: Powered by Vite `import.meta.glob` — adding a new file, section, video, or game level is automatically picked up by the running app with no server or client restarts.
- **🧱 Incremental Development**: Build one piece at a time (Explanation ➔ Video ➔ Game levels) with built-in graceful fallback states.
